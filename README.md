## My Data Analytics: Learning Objectives & Outcomes 

## Objectives - What to learn

- Foundations of data analysis: terminology, core concepts, roles, and the data analysis lifecycle 

- Data quality and collection: best practices, common pitfalls, and recognizing and addressing bias 

- Microsoft Excel as a tool for reviewing, cleaning, transforming, and visualizing data 

- Relational database concepts: how relational databases are structured, designed, and normalized 

- SQL for querying, managing, and analyzing data stored in a relational database 

- Communicating analytical findings through data storytelling and structured presentation 

- Professional workflows for organizing, documenting, and sharing data analysis work 

## Outcomes - I will be able to: 

- Apply the data analysis lifecycle to approach a business question systematically, from framing the question through communicating results 

- Evaluate a data set for quality issues, including missing values, inconsistencies, and potential sources of bias 

- Use Excel to clean and reshape data, apply lookup and logic functions, and create charts and PivotCharts to visualize findings 

- Design a normalized relational database schema, including an entity-relationship diagram, appropriate data types, and key constraints 

- Write SQL queries of increasing complexity to retrieve, filter, sort, aggregate, and join data across multiple related tables 

- Use subqueries and Common Table Expressions to answer multi-step analytical questions 

- Interpret query results to identify patterns, draw conclusions, and formulate a data-driven recommendation 

- Present analytical findings clearly and concisely to a non-technical audience, with supporting visualizations and a clear recommendation 

- Use git and GitHub to organize, version, and share project work throughout the analysis process
